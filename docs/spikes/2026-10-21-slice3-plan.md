# Slice 3 plan — shadow product (uv backlog scope, local-only)

Date: 2026-10-21. Spec: `docs/superpowers/specs/2026-10-19-support-triage-design.md`
§§10, 11.2, 14. Scope follows the §12 switch: `astral-sh/uv` backlog triage.

## What Slice 3 proves

A private read-only shadow digest over real data: an operator can open the
app, see queue health, read one digest grouped by route, open one proposal
with evidence, and open eval reports — all from stored local data, with zero
writes to GitHub and zero paid calls.

## Non-goals for Slice 3a (this build)

- No operator auth UI yet (single local operator; §9 full GitHub OAuth deferred
  to Slice 4 with App install). The UI is read-only so there is no approval to
  protect yet.
- No live polling, no outcome scorer cron, no cloud deploy, no backup rehearsal,
  no Langfuse/Sentry (those are Slice 3b/3c).
- No OpenAI/paid calls, no duplicate scoring, no tuning, no outreach packet.
  Outreach stays barred until §11.2 bars pass plus a genuine contribution.
- No writes of any kind: no approve/edit/reject endpoints in 3a (shadow
  judgments stay in notes, not in the app).

## Build steps

1. `GET /` overview: repo scope, stored issue/proposal counts, eval report
   list, health of local DB. Empty-state honest when the gitignored SQLite DB
   is absent.
2. `GET /digest` digest page: proposals grouped by route from `ProposalRow`,
   each with declared type/packages, missing fields, rationale. Backed by the
   uv-backlog SQLite DB when `DATABASE_URL` (or `--uv-backlog-db` path)
   points at it; otherwise empty with explanation.
3. `GET /proposals/{issue_number}` proposal detail: full rationale plus links
   to the public GitHub issue (link only, no fetch at request time).
4. `GET /evals` eval index: links the three frozen JSON reports with one-line
   descriptions; JSON served as files, not re-scored.
5. Tests: overview/digest/detail/evals routes return 200 with empty DB and
   with one seeded deterministic proposal; no network, no paid providers.
6. Docs: this plan + README status line for Slice 3a.

## Exit gate for 3a

- `uv run ruff check app tests`, `uv run pyright`, `uv run pytest -q` green.
- Manual: `uv run uvicorn app.main:app` renders `/`, `/digest`, one proposal,
  `/evals` from the local uv-backlog DB.
- Commit `feat: add read-only shadow digest UI`, push, CI green, comment #4.

## After 3a

- 3b: hourly poll of new uv issues (read-only PAT exception §9 recorded per
  sync), outcome scorer join vs maintainer actuals, Markdown digest artifact.
- 3c: one-cloud Docker deploy, backup/restore rehearsal, 7-day shadow run vs
  §11.2, then outreach packet decision.
